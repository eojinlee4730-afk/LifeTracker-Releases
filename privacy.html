LifeTracker 개인정보처리방침

최종 업데이트: 2026-10-21

LifeTracker는 운동, 식단, 체중 및 관련 생활 기록을 사용자가 직접 관리할 수 있도록 설계된 로컬 중심 앱입니다.

1. 수집 및 처리하는 정보

LifeTracker는 사용자가 앱에 직접 입력하거나 저장하는 다음 정보를 처리할 수 있습니다.

  • 운동 기록: 운동 종류, 세트, 반복 횟수, 중량, RPE, 운동 시간, 휴식 시간, 유산소 기록 및 기타 활동
  • 식단 기록: 음식, 섭취량, 칼로리 및 탄수화물·단백질·지방 정보
  • 신체 기록: 체중 및 사용자가 직접 입력하는 관련 수치
  • 사용자가 선택적으로 추가하는 메모 및 기타 기록

2. 데이터 저장 방식

LifeTracker의 주요 기록 데이터는 사용자의 기기 내부에 로컬로 저장됩니다. 현재 앱은 사용자 계정, 자체 백엔드 서버 또는 자체 클라우드 동기화 서비스를 사용하지 않습니다.

3. 데이터의 외부 전송 및 공유

LifeTracker는 사용자의 운동·식단·체중 기록을 개발자가 운영하는 서버로 전송하거나 판매하지 않습니다. 사용자가 Android의 공유 기능, 파일 내보내기 또는 백업 기능을 직접 사용하는 경우에는 사용자가 선택한 대상 앱이나 저장 위치로 데이터가 전달될 수 있습니다.

4. 기기 권한

앱 기능에 따라 다음 권한 또는 시스템 기능을 사용할 수 있습니다.

  • 알림 및 진동: 휴식 타이머 종료 등 운동 관련 알림 제공
  • 요약 이미지: 앱에서 생성한 PNG를 사용자가 선택한 폴더에 저장하거나 공유합니다. 기존 갤러리 사진을 읽거나 첨부하지 않으며 광범위한 사진/미디어 읽기 권한을 요청하지 않습니다.
  • 파일 선택 및 저장: 백업, 가져오기/내보내기, 요약 이미지 저장 등 사용자가 직접 실행하는 기능
  • 다른 앱 위에 표시: 사용자가 해당 기능을 활성화하고 Android가 허용하는 경우 휴식 타이머 표시

권한은 관련 기능을 제공하기 위해서만 사용되며, 사용자가 해당 권한을 허용하지 않으면 관련 기능 일부가 제한될 수 있습니다.

5. 데이터 보관 및 삭제

로컬 데이터는 사용자가 삭제하거나 앱 데이터를 제거할 때까지 기기에 남을 수 있습니다. 사용자는 앱 내 기록 삭제 기능을 사용하거나 Android 시스템 설정에서 앱 데이터를 삭제하여 로컬 데이터를 제거할 수 있습니다. 앱을 제거하면 Android 동작에 따라 앱 내부 저장소의 데이터가 삭제될 수 있습니다.

6. 제3자 제공 및 판매

LifeTracker는 사용자의 개인정보나 앱 기록을 제3자에게 판매하지 않습니다. 사용자가 명시적으로 공유 또는 내보내기를 실행한 경우를 제외하고, 개발자가 사용자의 기록을 제3자에게 제공하지 않습니다.

7. 아동의 개인정보

LifeTracker는 아동을 대상으로 설계된 서비스가 아닙니다. 관련 법령상 보호가 필요한 사용자의 데이터가 의도적으로 수집되는 구조를 운영하지 않습니다.

8. 방침 변경

앱 기능 또는 데이터 처리 방식이 변경되는 경우 본 개인정보처리방침도 수정될 수 있습니다. 중요한 변경이 있는 경우 이 페이지의 최종 업데이트 날짜를 갱신합니다.

9. 문의

개인정보처리방침 또는 LifeTracker의 데이터 처리 방식에 관한 문의는 GitHub 저장소의 Issues 기능을 통해 연락할 수 있습니다.

LifeTracker Privacy Policy

Last updated: October 21, 2026

LifeTracker is a local-first application designed to help users manage workout, diet, body-weight, and related personal tracking records.

1. Information Processed

LifeTracker may process information that users choose to enter or save in the app, including:

  • Workout records such as exercise type, sets, repetitions, weight, RPE, workout duration, rest timers, cardio, and other activities
  • Diet records such as foods, quantities, calories, carbohydrates, protein, and fat
  • Body records such as body weight and other values entered by the user
  • Optional notes and other records added by the user

2. Data Storage

LifeTracker stores its primary tracking data locally on the user's device. The current version does not use user accounts, a developer-operated backend server, or a developer-operated cloud synchronization service.

3. Data Transmission and Sharing

LifeTracker does not transmit workout, diet, or body-weight records to a developer-operated server and does not sell those records. If the user intentionally uses Android sharing, export, or backup features, data may be sent to the destination app or storage location selected by the user.

4. Device Permissions

Depending on the features used, LifeTracker may request or use the following device permissions or system capabilities:

  • Notifications and vibration: to provide workout-related alerts such as rest-timer completion
  • Summary images: app-generated PNGs can be saved to a user-selected folder or shared. The app does not read or attach existing gallery photos and does not request broad photo/media read permission.
  • File selection and storage: for user-initiated backup, import/export, or saving summary images
  • Display over other apps: if the user enables this feature and Android permits an external rest-timer overlay

Permissions are used only to provide the associated features. If a user declines a permission, the related feature may be unavailable or limited.

5. Data Retention and Deletion

Local data may remain on the device until the user deletes it or removes the app's data. Users can remove records using in-app deletion functions or clear app data through Android system settings. Uninstalling the app may remove app-internal data according to Android behavior.

6. Third-Party Sharing and Sale

LifeTracker does not sell personal information or tracking records. The developer does not share user records with third parties except when the user explicitly initiates a share or export action.

7. Children's Privacy

LifeTracker is not designed specifically for children and does not operate a system intended to knowingly collect children's personal information.

8. Changes to This Policy

This Privacy Policy may be updated if the app's features or data-handling practices change. The date at the top of this page will be updated when material changes are made.

9. Contact

For questions about this Privacy Policy or LifeTracker's data practices, users may contact the developer through the GitHub repository's Issues page.
